# AI 创作行业日报

> [打开产品介绍页 / Open the product page](https://yety1113.github.io/ai-creation-industry-daily/)

一个用于持续研究 AI 创作行业的 Codex Skill。它把每日信息流整理为可核验的日报、结构化原始记录，以及包含完整证据链的周度和月度阶段归档。

关注的不是泛 AI 新闻，而是 AI 如何改变内容创作、生产、分发、权利关系与商业化。

## 覆盖范围

- 文本、图像、视频、音频、音乐、3D、游戏与交互叙事模型
- 创作产品、生产工作流、开放范围、价格和许可变化
- 内容平台政策、AI 标记、推荐分发和创作者商业化
- 影视、广告、媒体、出版、设计和游戏行业的实际采用案例
- 训练数据、版权授权、诉讼、监管和行业标准
- 与创作行业直接相关的融资、合作、收购与成本变化

## 输出结构

```text
ai-creation-industry-daily/
├── INDEX.md
├── daily/YYYY/YYYY-MM/YYYY-MM-DD.md
├── records/YYYY/YYYY-MM/YYYY-MM-DD.md
└── archives/
    ├── weekly/YYYY-Www.md
    └── monthly/YYYY-MM.md
```

- **日报**：一句话判断、重点事件、趋势信号、观察清单和来源索引。
- **原始记录**：保存每个事件的时间、主体、状态、事实摘要、趋势标签、证据等级和可点击来源。
- **阶段归档**：总结趋势、反例、不确定性、机会和风险，并完整汇入周期内的逐日原始记录。
- **索引**：连接所有日报、原始记录和阶段归档，便于长期检索。

## 为什么保留原始记录

只有趋势总结会丢失当时的证据边界。这个 Skill 会把每条日常信号分配稳定记录 ID，并在周报、月报中保留原始措辞、状态、证据等级和链接。事实后来发生变化时，通过“状态更新/更正”追加记录，而不是覆盖历史。

“原始记录”是当天形成的结构化研究笔记，不是复制整篇受版权保护的文章。

## 安装

将本仓库克隆或复制到 Codex 的个人 Skill 目录：

```text
~/.codex/skills/ai-creation-industry-daily/
```

重新开启任务后，可通过 `$ai-creation-industry-daily` 显式调用；与 AI 创作行业日报、趋势扫描或阶段归档相关的请求也可以自动触发。

## 快速开始

生成今天的日报：

```text
使用 $ai-creation-industry-daily 生成今天的 AI 创作行业日报。
```

生成阶段归档：

```text
使用 $ai-creation-industry-daily 汇总本月记录，生成包含趋势总结、每日原始记录和全部来源链接的月度归档。
```

补录或纠错：

```text
把这条新来源补入 2026-09-27 的记录，并更新相关日报和阶段归档，但保留原记录的修订痕迹。
```

## 信源原则

优先使用官方公告、产品文档、论文、监管或司法原文；重要结论尽量以一手来源为主，争议性或高影响结论再用独立来源交叉验证。Skill 会区分事件发生日、来源发布日期和采集时间，并避免把旧闻重新传播误判为当天新事件。

## 归档规则

- 进入新 ISO 周后的首次运行，检查并补建上一周归档。
- 进入新月份后的首次运行，检查并补建上一月归档。
- 用户指定区间或项目里程碑时，可立即创建专项归档。
- 缺失日期会明确标记，不会虚构新闻补齐。
- 阶段归档不能只给每日文件链接，必须直接包含逐日原始记录和可点击来源。
