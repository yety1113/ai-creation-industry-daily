# 文件格式

只在创建、补录或归档日报库时读取本文件。栏目可以按用户需要扩展，但标为“必填”的追溯字段不得省略。

## `records/YYYY/YYYY-MM/YYYY-MM-DD.md`

timezone: Asia/Shanghai

## 汇总规则

1. 先枚举区间内实际存在的 `records/` 日文件，计算覆盖日与缺失日。
2. 解析所有记录 ID；重复 ID 是错误，必须先修正。
3. 趋势结论只能引用区间内真实记录，跨期背景要明确标为背景并另附来源。
4. 将原始记录按日期、记录 ID 排序汇入归档；保留全部 HTTP(S) 链接。
5. 相对链接若从新目录失效，可改写为有效相对路径；外部 URL 不做短链替换。
6. 核对 frontmatter 的 `covered_days` 与 `record_count`，再更新索引。
